MaxEco is a three step power slider in the system tray: **Normal**, **Eco** and **MaxEco**. First public release.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/MaxEco/main/install.sh | bash
```

Or pick the package for your distro below:

| Distro | File |
|---|---|
| Arch and derivatives | `maxeco-1.2.0-1-x86_64.pkg.tar.zst` (`sudo pacman -U ./...`) |
| Debian, Ubuntu and derivatives | `maxeco_1.2.0-1_amd64.deb` (`sudo apt install ./...`) |
| Fedora, openSUSE, Bazzite | `maxeco-1.2.0-1.x86_64.rpm` (`sudo dnf install ./...`, `zypper`, `rpm-ostree`) |

`SHA256SUMS` has the checksum of every file, and the installer checks it before installing. Needs x86_64, systemd, polkit 0.106+ and glibc 2.34+.

## What is new in 1.2.0

- Three levels instead of on and off. **Eco** cuts the CPU and GPU power and games stay playable, **MaxEco** goes to the lowest power the hardware allows.
- The mouse wheel over the icon changes the level, down toward MaxEco and up toward Normal.
- Switching between Eco and MaxEco goes straight from one to the other.
- 60 Hz screens in MaxEco is now an option, off by default, so the screens never blink unless you ask for it.
- The graphics card fans are left as they were. On an RTX 3060 Ti the lowest speed NVML accepts (30 %) does not spin the fans at all.
- The root helper runs on glibc 2.34 or newer.

Measured on a Ryzen 7 9800X3D + RTX 3060 Ti with a light game scene: CPU 38.8 / 28.5 / 23.9 W and GPU 106.5 / 57.1 / 33.7 W for Normal / Eco / MaxEco.
