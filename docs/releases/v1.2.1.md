Install or update in one line, on Arch, Debian, Ubuntu, Fedora, openSUSE and their derivatives:

```sh
curl -fsSL https://raw.githubusercontent.com/gabrielmf1998/MaxEco/main/install.sh | bash
```

Running it again over 1.2.0 updates MaxEco and restarts the tray icon, keeping the level that was on.

## What is new in 1.2.1

- **The tray icon lights up with the level.** Switched off (a grey outline) in Normal, lit up to the middle in Eco, fully lit with a glow in MaxEco. No blinking, no animation.
- The panel is told to redraw the icon only when the level really changes, not when only the tooltip changes.
- The icons have new names (`maxeco-tray-normal`, `maxeco-tray-eco`, `maxeco-tray-max`, and `maxeco` for the application menu), so no desktop keeps showing the old ones from its icon cache.

Measured on the running tray: 60 to 64 KB of memory, and over 3 minutes idle 0 wakeups and 0 ns of CPU.

| Distro | File |
|---|---|
| Arch and derivatives | `maxeco-1.2.1-1-x86_64.pkg.tar.zst` (`sudo pacman -U ./...`) |
| Debian, Ubuntu and derivatives | `maxeco_1.2.1-1_amd64.deb` (`sudo apt install ./...`) |
| Fedora, openSUSE, Bazzite | `maxeco-1.2.1-1.x86_64.rpm` (`sudo dnf install ./...`, `zypper`, `rpm-ostree`) |

`SHA256SUMS` has the checksum of every file, and the installer checks it before installing.
